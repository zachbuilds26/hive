# CREDITS

HIVE is an original implementation built with publicly available building
blocks. Nothing in this repository is copied from another project's source.

## Concept inspiration

- **LiquidMesh** (github.com/liquidmesh-fi/liquidmesh, MIT) — the idea of a
  multi-agent trading economy on X Layer (agents that sell intelligence to
  each other via x402). HIVE independently implements this concept with its
  own architecture, code, frontend, and branding.

## Public building blocks used

- **OKX OnchainOS APIs** — market signals, token security, DEX aggregator
- **x402 payment protocol** — OKX open payment SDKs
- **X Layer** (chain 196 mainnet / 195 testnet) — OKX EVM L2
- **Uniswap V3 / QuickSwap** — onchain liquidity for swaps
- **OpenAI API** — LLM scoring for the Analyst agent
